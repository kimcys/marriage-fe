Getting started

1 Signing in

Every action in this system requires an account. Ask your administrator for your email and password if you don't have one yet.

Sign in
  1. Open the site in your browser.
  2. Type your Email and Password into the two boxes.
  3. Click Sign in.
Two kinds of accounts. An Admin can do everything, including delete batches, links, records, and exports. A Reviewer can do everything except delete — any Delete button simply won't appear for a Reviewer account. Both can submit links, review records, and correct data.
Organizing work

2 Creating a batch

A batch is a folder for one set of registers — for example, all the pages from one physical volume. You'll create a batch before submitting any files to it.

Create a batch
e.g. Kajang Register Vol. 12 Description (optional) Create batch
  1. On the home page, find the Create a batch section at the top.
  2. Type a short, recognizable Name — something that tells you what's inside at a glance.
  3. Optionally add a Description with more detail.
  4. Click Create batch. It appears immediately in the Batches list below, and you're ready to add files to it.
  5. Click the batch's name at any time to open it.
Adding files

3 Submitting a OneDrive link

Files are added to a batch by pasting a OneDrive share link — not by uploading files directly. One link can point to a whole folder, and every file inside it is picked up automatically.

Submit a OneDrive link
https://1drv.ms/... Submit link
  1. Open the batch you want to add files to.
  2. Find the Submit a OneDrive link section.
  3. Paste the OneDrive share link into the box.
  4. Click Submit link (or press Enter).
What happens next The system downloads every file the link points to, figures out on its own whether each page is handwritten or typed and which register type it is (Nikah, Cerai, or Rujuk), then starts extracting the data. You'll see a banner — "1 link(s) downloading and classifying — this can take a few minutes for many files" — while this is in progress. This is normal; larger folders simply take longer. You don't need to keep the page open — check back later.
If a link fails It will show a FAILED tag with a short error message underneath. Click the Retry link next to it to try again — for example, after fixing a sharing-permission problem on the OneDrive side.
Tracking progress

4 Watching jobs process

Each page from your files becomes one job. The Jobs section on the batch page lists every one of them, with its own status.

StatusWhat it means
PENDINGWaiting in line to be processed.
PROCESSINGBeing read right now.
COMPLETEDDone. Its data is ready to review below.
FAILEDSomething went wrong. An error message is shown; click Retry to try again.
CANCELLEDStopped manually (see below). Can also be retried.
  1. Use the status dropdown above the job list to filter (for example, show only Failed jobs).
  2. For a COMPLETED job, click View records to see the data extracted from that page right there, or Download to get the original file.
  3. For a FAILED or CANCELLED job, click Retry.
Stopping a batch While a batch shows PROCESSING, a Stop processing button appears at the top. Clicking it cancels every job that hasn't started yet and stops any that are currently running — useful if you submitted the wrong link and want to abort before it finishes.
The most important step

5 Reviewing and correcting records

Once a job completes, it produces one or more records — the actual extracted data (names, IC numbers, dates, and so on). This is where you check the computer's work and fix anything it got wrong or couldn't read.

You can reach the records table in three places, all working the same way:

  1. Click View records on any completed job, to see just that page's data.
  2. Scroll to the Review queue section on the batch page, to see every record in the batch at once, with search and filter tools.
  3. On the home page, use All records to search across every batch at the same time.

Understanding a record's status

StatusWhat it means
Needs review At least one field couldn't be read confidently and is left for you to fill in — its cell is highlighted and already open for typing.
Complete Every field is filled in. No action needed unless you spot a mistake.

How to correct a field

  1. Find the record's row, and the column for the field you want to fix (for example, Full Name or IC Number).
  2. If the cell has a pale orange background, it's a field the system couldn't read — it's already open for you to type into directly. For any other cell, click it once to open it for editing.
  3. Type the correct value.
  4. Click anywhere else, or press Enter, to save. There's no separate save button — it saves the moment you click away.
Once every flagged field is filled in The record's status automatically changes from Needs review to Complete — there's no separate "approve" button to click. Simply filling in the missing information is enough.
Checking against the original Click the file name shown in the File column (for example page_04.pdf) to open the original scanned page in a new tab, so you can compare it side-by-side with what was extracted before correcting anything.
Admin accounts see a Delete link at the end of each row, for removing a record that shouldn't exist at all (for example, a duplicate or a blank page misread as data). Reviewer accounts don't see this option — they can correct data freely, but not delete it.
Getting your data out

6 Exporting results

Once you're happy with a batch's records, export them to a spreadsheet.

Export
XLSX ▾ Generate export
  1. Open the batch and scroll to the Export section at the bottom.
  2. Choose a format: XLSX (Excel) or CSV.
  3. Click Generate export.
  4. Wait for its status to reach COMPLETED, then click Download.
Tip You can generate as many exports as you like — for example, one now and another later after making more corrections. Each one is saved in the list with its own download link.
